# Nexus Tecnologia Central

Painel central para gerenciamento e suporte dos sistemas da Nexus Tecnologia.

## Objetivo

Centralizar em um único painel o cadastro, acompanhamento, suporte e monitoramento dos sistemas administrados pela Nexus Tecnologia.

## MVP

- Dashboard
- Cadastro de sistemas
- Monitoramento de status
- Central de suporte
- Histórico de atividades
- Configurações
- Acesso de usuário único

## Próximos passos

A primeira versão é uma interface web estática. A persistência de dados, autenticação e monitoramento real serão adicionados nas próximas etapas.
