# Nexus Finance Web

Sistema web financeiro com cadastro/login local, dashboard, entradas, saídas, serviços, gastos e parcelamento.

## Parcelamento
Ao informar valor total e número de parcelas, o sistema cria uma movimentação para cada mês, com valor proporcional e vencimento mensal.

## Observação
Esta versão estática usa localStorage do navegador. Para dados realmente online e multi-dispositivo, a próxima etapa deve ligar o frontend a um backend/banco na nuvem.

## Acesso
Abra `finance/index.html`.
